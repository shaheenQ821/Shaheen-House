# SHAHEEN HOUSE — دليل المنزل

موقع ثابت متجاوب بالعربية والإنجليزية لمنزل شاهين وحسين ومحمد. يتضمن ملفات السكان، دليلًا نصيًا للغرف، قواعد منزلية عامة، وقسمًا توضيحيًا للمساهمات.

## الملفات
- `index.html` — الصفحة الرئيسية
- `residents.html` — ملفات السكان
- `rooms.html` — دليل الغرف
- `rules.html` — قوانين المنزل
- `donations.html` — المساهمات والمصاريف
- `styles.css` — التصميم المتجاوب
- `script.js` — التبديل بين العربية والإنجليزية والقائمة المتنقلة
- `assets/favicon.svg` — أيقونة الموقع
- `assets/hussein.jpg` — صورة حسين
- `assets/mohammad.jpg` — صورة محمد

## قبل النشر
- راجع أوصاف السكان وتأكد أن الجميع مرتاحون لعرضها.
- خريطة الغرف تخطيط توضيحي، وليست مخططًا دقيقًا.
- لا تضف العنوان الكامل للمنزل أو أرقام الحسابات أو بيانات شخصية حساسة إلى موقع عام. تأكد من موافقة حسين ومحمد على نشر صورهما إذا كان الموقع عامًا.
- قسم المساهمات لا يجمع المدفوعات ولا يحفظ سجلات مالية. أضف أي طريقة دفع فقط بعد الاتفاق عليها وتوضيحها.
- قوانين المنزل مسودة تنظيمية وليست عقدًا قانونيًا.
- إن رغبت بجعل الموقع خاصًا بالسكان فقط، تذكّر أن GitHub Pages للمستودعات العامة ينشر موقعًا عامًا؛ لا تضع معلومات لا تريد نشرها.

## النشر على GitHub Pages
1. أنشئ مستودعًا في GitHub وارفع الملفات كلها إلى الجذر.
2. افتح `Settings → Pages`.
3. اختر `Deploy from a branch`، ثم الفرع `main` والمجلد `/ (root)`.
4. أضف `alfares.nl` ضمن `Custom domain`.
5. اضبط DNS لدى شركة الدومين وفق الدليل الرسمي، ثم فعّل HTTPS عند توفره.

الدليل الرسمي: https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site
